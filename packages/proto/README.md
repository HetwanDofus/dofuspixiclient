# `@dofus/proto`

Versioned protobuf contracts shared by the Dofus client and server.

```ts
import { ClientMessageSchema, DofusMessageSchema } from "@dofus/proto";
import { AccountSendIdentitySchema } from "@dofus/proto/account_pb";
import { GatewayFrameSchema } from "@dofus/proto/gateway/v1/gateway_frame_pb";
```

The package contains ESM JavaScript, TypeScript declarations and source maps.
Generated sources are rebuilt from `proto/*.proto` before packaging.
